# EDUCARED
## Repositorio de Recursos Educativos Digitales

Prototipo académico para el **Instituto Universitario Nuevos Horizontes**, contexto ficticio ubicado en Montería, Córdoba, Colombia.

### Propósito
Organizar, describir, consultar y compartir Recursos Educativos Digitales (RED) que apoyen experiencias de enseñanza y aprendizaje flexibles, inclusivas y colaborativas.

### Colecciones
1. Pedagogía y didáctica.
2. Competencias digitales.
3. Educación inclusiva.
4. Ciencias y pensamiento crítico.
5. Ciencias sociales y humanidades.
6. Aprendizaje autónomo.

### Metadatos: Dublin Core y LOM
El registro de cada recurso debe incluir, según corresponda:
- Identificador, título, descripción, tema y palabras clave.
- Creador, contribuidor, fecha, idioma y tipo de recurso.
- Formato, identificador del recurso, fuente, derechos y relación.
- Nivel educativo, audiencia, duración, requisitos técnicos y accesibilidad.

### Roles
- **Administrador:** administra colecciones, usuarios, metadatos y publicación.
- **Docente:** propone y actualiza recursos.
- **Evaluador:** revisa calidad, pertinencia, derechos y accesibilidad.
- **Estudiante:** consulta y utiliza recursos publicados.

### Flujo editorial
Carga → revisión → aprobación → publicación → consulta y uso.

### Alcance y limitaciones
Esta entrega es un prototipo estático demostrativo. El buscador y los filtros funcionan en el navegador. No incluye autenticación, almacenamiento de archivos, formularios conectados, base de datos ni flujo real de aprobación. Esas funciones requieren backend y gestión de usuarios.

### Publicación con GitHub Pages
1. Abrir Settings del repositorio.
2. Entrar a Pages.
3. En Build and deployment seleccionar **Deploy from a branch**.
4. Elegir branch `main` y folder `/ (root)`.
5. Guardar y esperar la publicación.
